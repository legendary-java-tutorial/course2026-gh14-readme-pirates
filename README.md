# Угадай число: пиратская версия

Игра в терминале на пиратскую тему: пират прячет число, а вы ищете его по подсказкам «выше» и «ниже». Все реплики пирата — в docs/game.json, свою тему можно сделать без единой строки кода.

> [!WARNING]
> Игра работает на Node.js 24.12+.

## Как запустить

```bash
npm install
npm start
```

Сначала `npm install` (один раз), потом `npm start`.

![Скриншот партии](images/screenshot.png)

## Режимы

| Режим | Числа | Победа |
|---|---|---|
| classic | от 1 до 100 | сундук твой! |
| quick | от 1 до 10 | йо-хо-хо! |

## Что сломалось и как починил

- **Сломал тексты игры.** Удалил запятую в docs/game.json, и `npm test` покраснел. Вернул файл из последнего коммита командой `git restore docs/game.json` и поправил заново.
